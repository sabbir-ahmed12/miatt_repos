# Register Circles

**Problem Statement:**  Write a program that registers two 2D images.  The program will be used more than 1 million times to register pairs of images to be supplied in the future.  

For this assignment, use two 2D images of circles.  
img1.png:  30mm diameter centered at 50mm, 50mm
img2.png:  60mm diameter centered at 200mm,200mm


Step 1: Write a EngineeringDesignPrinciples.md file that describes the approach you are taking.
Step 2: Write the algorithm
Step 3: Write a ExperimentalResults.md file that convinces 20 other people in your research area that your solution is trustworthy and appropriate.

---

## Implementation

This repository implements the registration pipeline using **ITK** (Insight Toolkit)
with a `Similarity2DTransform` (scale + rigid body) and a 4-level multi-resolution
pyramid. Images are stored as **NRRD** — a format that carries physical spacing,
origin, and direction cosines so the metric operates in mm without coordinate
assumptions.

### Prerequisites

[pixi](https://pixi.sh) manages all dependencies (ITK, CMake, Ninja, Python, matplotlib).

```bash
pixi install   # one-time environment setup
```

### Build

```bash
pixi run build
# equivalent to:
pixi run cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
pixi run cmake --build build
```

For a Debug build (stepping through ITK pipelines):
```bash
pixi run cmake -B build-debug -G Ninja -DCMAKE_BUILD_TYPE=Debug
pixi run cmake --build build-debug
```

### Generate test images

```bash
pixi run generate
# writes img1.nrrd (30 mm circle at (50,50) mm, 50×50 px)
# and   img2.nrrd (60 mm circle at (200,200) mm, 80×80 px)
```

### Run registration

```bash
pixi run register
# reads img1.nrrd (fixed) and img2.nrrd (moving)
# writes registered.nrrd and convergence.csv
```

Expected output:
```
=== Registration result ===
  Scale            : ~2.0000  (expected ~2.0)
  Angle (rad)      : ~0.0000  (expected ~0.0)
  Translation      : (~150.0000, ~150.0000) mm  (expected ~(150, 150))
  Best metric      : ~0.0008
  Convergence CSV  : convergence.csv
```

### Generate convergence GIF

```bash
pixi run gif
# reads convergence.csv, writes convergence.gif
```

The GIF animates the MSE metric vs. iteration number, colour-coded by pyramid
level, making it easy to see how the 4-level coarse-to-fine strategy drives
convergence.

### Run tests

```bash
pixi run test
# runs 7 CTest tests including a scale-accuracy regex check
```

### Full pipeline (generate → register → GIF → test)

```bash
pixi run gif && pixi run test
```
